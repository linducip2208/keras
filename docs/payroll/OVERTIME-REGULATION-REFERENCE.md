# Overtime Regulation Reference

- Dasar: **Kepmenakertrans No. 102/MEN/VI/2004**.
- Upah/jam = upah sebulan / 173.
- Hari kerja: jam ke-1 = 1,5×; jam ke-2 dst = 2×.
- Hari istirahat mingguan/libur resmi (5 hari kerja): jam 1–8 = 2×; jam 9 = 3×;
  jam 10–11 = 4×. (6 hari kerja): jam 1–7 = 2×; jam 8 = 3×; jam 9–10 = 4×.
